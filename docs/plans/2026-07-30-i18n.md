# 多語言（繁中／英文）Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 讓 CLOCK LAB 根頁與 8 座時鐘 PWA 同時支援繁體中文與英文，首次依瀏覽器語言自動判定，使用者可手動切換且跨全站沿用。

**Architecture:** HTML 裡的中文就是 `zh` 原文，每頁內嵌一份**只有英文**的字典。時鐘頁的可翻譯元素本來就都有 id（`bInstall` / `bWake` / `bFull` / `waveLabel` / `keys`），所以字典直接用 **element id 當 key**，markup 零改動；根頁的元素多半沒有 id，改用 `data-i18n` 屬性。切換語言 = 寫 `localStorage` 後 `location.reload()`，不做雙向 DOM 還原。

**Tech Stack:** 原生 HTML / CSS / vanilla JS（無框架、無建置步驟、無 npm）。驗證工具是 `python tools/check.py` 與 `python tools/build.py`。

Spec: `docs/specs/2026-07-30-i18n.md`

## Global Constraints

- **localStorage key**：`clocklab.lang`，值只有 `'zh'` 或 `'en'`。8 座時鐘與根頁同 origin，一個 key 全站生效。
- **判定順序**：`localStorage` → `navigator.language.startsWith('zh')` → 預設 `en`。
- **旗標變數名一律 `LANG_EN`**（boolean）。不要用 `L`：`receipt/index.html` 已有 `L_BIG`、`LH`、`lh`，容易誤讀。動手前先 `grep -n 'LANG_EN' <檔案>` 確認無衝突。
- **字典變數名一律 `EN`**。時鐘頁用 element id 當 key，`_title` 是唯一例外（對應 `document.title`，前綴底線表示它不是 element id）。
- **文字寫入一律用 `replaceChildren(s)`**，一次呼叫、可搭配 `?.` 選擇性串連（`el?.textContent = s` 是不合法的賦值目標）。
- **絕不對含子元素的節點寫 textContent／replaceChildren**：會吃掉子元素。根頁 `index.html:109` 的 `<span>原始碼在 <a>GitHub</a></span>` 必須先把文字包成自己的 `<span data-i18n>`。
- **語言鈕 id 一律 `bLang`**，label 顯示**要切去的語言**：目前中文顯示 `EN`，目前英文顯示 `中`。
- **時鐘頁的語言鈕一律放進既有的 `#ctrl` 容器**。各頁 CSS 用的是裸 `button` 元素選擇器（無 class），放進去自動吃到樣式，不需要新增 CSS。
- **`?embed=1` 時語言鈕會跟著 `#ctrl` 一起隱藏**（`body.embed #ctrl{display:none}`），閒置時也會跟著 `body.rest #ctrl` 淡出。這是期望行為，不要為它加例外。
- **`life/index.html` 不加語言鈕**：它整個 body 只有 `<canvas id="c">` 與 `<div id="scan">`，沒有任何控制列容器。
- **不要翻譯 bricks 與 life 畫面上的英文**（`SCRAP` / `TODAY` / `NEXT SHIFT` / `BUILD` / `CONWAY LIFE v1.0` / `GEN` / `POP` / `RULE B3/S23`）。那是刻意的美術設計，不是待翻譯的中文。這兩座的語言切換只影響 `<title>` 與 `<html lang>`。
- **`tools/build.py` 不需要修改**：它整包帶 `clock.json` 的欄位、只剔除 `shot`，新欄位會自動流進 `dist/clocks.json`。
- **`<meta name="description">` 改成中英並排在同一句**（中文句在前，英文句在後，中間一個半形空格）。靜態站無法依語言切換，一頁只能一份。
- **每個 task 結束都要跑 `python tools/check.py`**，必須 `ok`。

### canonical 語言片段（時鐘頁專用，逐字照抄）

插在該頁 IIFE 的最前面（`'use strict';` 之後）。因為 `<script>` 在 body 結尾，此時 DOM 已解析完成，可以直接抓元素。放在最前面是為了讓後面的繪圖程式碼（receipt 的 `WD`、galaga 的 `bFmt`）拿得到 `LANG_EN`。

```js
// ── 語言 ────────────────────────────────────────────────────────
const EN = { _title:'', bInstall:'Install', bWake:'Stay awake', bFull:'Fullscreen' };
const LANG_EN = (localStorage.getItem('clocklab.lang')
              || (navigator.language.startsWith('zh') ? 'zh' : 'en')) === 'en';
if(LANG_EN){
  document.documentElement.lang = 'en';
  document.title = EN._title;
  for(const [k, s] of Object.entries(EN)) document.getElementById(k)?.replaceChildren(s);
}
{
  const b = document.getElementById('bLang');
  b.textContent = LANG_EN ? '中' : 'EN';
  b.onclick = () => { localStorage.setItem('clocklab.lang', LANG_EN ? 'zh' : 'en'); location.reload(); };
}
```

各 task 只需替換 `EN` 物件的內容（`_title` 與該頁實際有的按鈕 id）。`_title` 不對應任何元素，`document.getElementById('_title')` 回傳 `null`，被 `?.` 安全略過。
