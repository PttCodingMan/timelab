## 一、四張離屏 canvas，一個遮罩決定一切

霧玻璃的關鍵是「霧的地方是**模糊的背景**，不是白色半透明貼片」。用一層白紗蓋上去
永遠像塑膠布；真正的作法是同一張背景畫兩份，一份清楚一份模糊，用遮罩決定哪裡露哪份。

| canvas | 內容 | 更新時機 |
|---|---|---|
| `bgSharp` | 夜窗光斑：深藍黑底＋6～8 個 radial gradient 光暈 | 只在 layout 時畫一次 |
| `bgFog` | 對 `bgSharp` 下 `ctx.filter='blur(18px)'` 重畫一份，再蓋 `rgba(232,240,245,.55)` | 只在 layout 時畫一次 |
| `mask` | **白＝有霧、透明＝已擦乾淨**，只有 alpha 有意義 | 每次擦、每次爬回 |
| `scr` | 合成暫存 | 每幀 |

每幀三次 drawImage，沒有 per-pixel JS：

```js
ctx.drawImage(bgSharp, 0, 0);
sctx.globalCompositeOperation = 'source-over';  sctx.clearRect(...);
sctx.drawImage(bgFog, 0, 0);
sctx.globalCompositeOperation = 'destination-in'; sctx.drawImage(mask, 0, 0);
ctx.drawImage(scr, 0, 0);
```

擦拭＝在 `mask` 上用 `destination-out` 加一枝軟圓刷。使用者拖曳、手指寫字、呵氣補霧，
全部只是對這一張 `mask` 做加減，其餘程式碼一行都不用知道發生了什麼事。

**背景的隨機必須有種子。** 光斑座標、刷痕抖動一律走 mulberry32（固定 seed），
**全檔不准出現 `Math.random()`** —— 縮圖每次 CI 重拍，背景每次長不一樣的話 thumbnail 會亂跳。

## 二、霧從邊緣往內爬（這座鐘的核心手法）

只對 `mask` 做，每 tick 一次：

```js
scr.clear(); sctx.filter = `blur(${CREEP*F}px)`; sctx.drawImage(mask,0,0); sctx.filter='none';
mask.clear();
for(let i=0;i<3;i++) mctx.drawImage(scr,0,0);   // α = 1-(1-α)³
```

blur 把擦痕邊界的 alpha 從 0 拉成一段漸層，自疊三次再把中間值推回不透明
（0.3 → 0.66、0.5 → 0.875），洞的正中央仍是 0。淨效果就是洞從邊緣往內縮。
**細筆畫兩側同時被吃、先斷；粗的最後死** —— 這正是要的視覺。

| 參數 | 初值 | 為什麼 |
|---|---|---|
| `TICK` | 1000 ms | 每 tick 邊界只推進約半個 px，1 Hz 的階梯肉眼看不出來；跑 10 Hz 會在十秒內把字吃光 |
| `CREEP` | `0.003`（× 字高 F） | 筆畫半寬約 `0.5*PENW*F`，要撐到第 50 秒才斷 |
| 自疊次數 | 3 | 2 次爬太慢、4 次以上洞邊會出現硬邊 |

這三個數字**一定要在瀏覽器裡對眼睛調**，寫死的初值只是起點。

**畫面邊緣要釘住**：blur 會從畫布外採到透明，連續跑一分鐘會讓四個邊的霧被啃掉一圈。
每次 tick 後補一筆 `mctx.strokeStyle='#fff'; mctx.lineWidth=8; mctx.strokeRect(4,4,w-8,h-8)`。

## 三、一分鐘的節奏

| 時間 | 動作 | `runs` |
|---|---|---|
| `0.0 – 1.3s` | **呵氣**：一團白霧從畫面下緣中央漲開蓋滿 `mask`（舊字一起被埋） | 1 |
| `1.3 – 4.3s` | **寫字**：四個數字依序沿筆順擦出，每字 0.62s、字間 0.10s，最後點兩顆冒號 | 1 |
| `4.3 – 5.8s` | **停住**：不爬，讓人把時間看完 | 0 |
| `5.8 – 60s` | **被吃**：每秒一次 tick，約第 50 秒糊乾淨 | 0 |

- 進場（首次載入、resize 之後）走同一套，不特別處理。
- **`runs` 這個變數名是硬性的**，`tools/simulate.js:85-89` 的探針直接讀 `runs.length`。
  爬回**不算** run（它從不結束），所以每個檢查點都會是 0。
- 那 1.5 秒的停住不只是為了好看：縮圖就拍在這個窗口裡，狀態完全靜止 → 兩次拍出來 bytes 相同。

## 四、筆順資料照抄 zen

`zen/index.html:254-277` 的 `PATHS`（十個數字、每筆一條三次貝茲鏈、座標在 0..1 字格）
連同 `meta()`／`poly()` 的取樣邏輯（`:299-329`）整段複製過來。
**這 repo 的明文約定是各作品不共用程式碼**（`README.md:1-17`），複製一份是對的，不要抽共用檔。

抄過來之後要改的：

- `SLANT` 保留（右手寫字本來就往右倒），`jit()` 的抖動幅度可以加大一點 —— 手指在玻璃上比耙子在沙上抖。
- 不需要 `prof()` 的可變筆寬：手指粗細是固定的。刷寬 `BRUSH = 0.11 * F`。
- 刷子是 `createRadialGradient` 做的軟邊圓（中心 `rgba(0,0,0,1)`、邊緣透明），
  沿折線每隔 `BRUSH*0.25` 蓋一枚。硬邊圓會讓擦痕像貼紙，而且爬回時邊界收縮得不自然。

## 五、外觀

- **底色** `#0a0e14`，夜窗的暗。
- **光斑** 6～8 個，半徑 `0.10~0.28 × min(w,h)`，顏色在暖橘 `#ffb46b`、冷白 `#cfe6ff`、
  綠燈 `#8fd6a8` 之間挑，alpha `0.35~0.7`。底部密、上方疏 —— 街燈在下面。
- **霧** `rgba(232,240,245,.55)` 白紗＋`blur(18px)`。亮度要夠高，擦開才有「透出夜色」的反差。
- **字** 沒有自己的顏色 —— 字就是「霧被擦掉的地方」，露出的是 `bgSharp`。這是整座鐘的重點。
- **版面** 四個數字橫排，字高 `F = 0.30 * min(w, h*1.4)`，字間 `0.16*F`，冒號兩點在正中。
  直式（`h > w`）時 F 改用 `0.34 * w`。
- **殘留水氣**：擦痕邊緣一圈很淡的亮邊（在 `mask` 上先用 `source-over` 畫一枝比刷子大 1.3 倍、
  alpha 0.25 的白圓，再用 `destination-out` 畫本體）。沒有這一層，擦痕邊界會太乾淨、像剪紙。

## 六、互動

`pointerdown` / `pointermove` → 在 `mask` 上沿指標軌跡擦一道（同一枝刷子），之後照樣被霧吃回去。
`window.addEventListener` 在假 DOM 是 noop，模擬環境不會走到這裡。
`touch-action: none` 免得手機上變成捲動。

## 七、假 DOM 的地雷（會 crash，不是會變醜）

`tools/simulate.js:42-50`：**只有 id 為 `c` 的那個 canvas 有 `getContext`**，
`document.createElement('canvas')` 回傳的 stub **沒有 `getContext`**。
這座鐘要開四張離屏 canvas，直接寫 `oc.getContext('2d')` 會在模擬裡爆掉。

```js
const mk = (w,h) => { const e = document.createElement('canvas');
  const g = e.getContext && e.getContext('2d');
  if(g){ e.width=w; e.height=h; } return g && {e, g}; };
```

任一張開不出來 → 設 `HEADLESS = true`，`render()` 開頭直接 `return`。
狀態機（`runs`、`want`/`drawn`、`dataset.shown`）照跑，模擬只看這三樣。

其餘三條硬線同 flip：

- 只有**一個無屬性的 `<script>`**（`simulate.js:83` 的正則貪婪比對）。
- 程式包在 `(() => { 'use strict'; ... })();`，`})();` 必須是全檔**最後一次**出現（`:91` 用 `lastIndexOf`）。
- serviceWorker 註冊寫在同一行：`if(!EMBED && 'serviceWorker' in navigator && ...)`（`check.py:37` 的正則不跨分號）。

## 八、`dataset.shown` 契約

`document.documentElement.dataset.shown = p2(h) + p2(m)`，**24 小時制、補零**。
寫入時機：**寫字動畫結束那一幀**（t≈4.3s）。檢查點在跨分後 +7 秒，綽綽有餘。
進場時同理，不提早寫。

## 不做的事

- **水滴流痕不做。** 擦完流一道水下來很美，但流痕要自己的粒子系統，而且它跟「霧爬回來」
  是兩套互相打架的動畫。要就之後單獨開一版。
- **秒不做、日期不做、主題切換不做。**
- **`ctx.filter` 不做 fallback。** Safari 17.4 起支援，更舊的瀏覽器會看到白紗但不模糊 —— 還是能看時間。
- **不碰** 其他四座、`tools/`、根 `index.html`、`.github/`。
