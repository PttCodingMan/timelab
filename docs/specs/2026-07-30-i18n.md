# 多語言（繁體中文 / 英文）

2026-07-30

讓 CLOCK LAB 的根頁與 8 座時鐘同時支援繁體中文與英文。首次造訪依瀏覽器語言自動判定，使用者可手動切換，選擇跨全站沿用。

## 決策

| 項目 | 決定 |
|---|---|
| 範圍 | 根頁 + 8 座時鐘頁 + `clock.json` + `manifest.webmanifest`，含 receipt 畫進 canvas 的中文 |
| 語言判定 | 首次 `navigator.language`，之後讀 `localStorage['clocklab.lang']` |
| 切換 | 根頁右上角一顆鈕；有按鈕列的 7 座時鐘各一顆（life 不加） |
| manifest | 改純英文，`lang: "en"` |
| `<meta description>` | 中英並排在同一句 |

## 機制：只維護一份英文字典

HTML 裡的中文**就是** `zh` 原文，字典只存 `en`。中文使用者不執行任何字串替換。

```html
<button data-i18n="install">安裝</button>
```

```js
const EN = { install:'Install', awake:'Stay awake', full:'Fullscreen' };
const lang = localStorage.getItem('clocklab.lang')
          || (navigator.language.startsWith('zh') ? 'zh' : 'en');
const L = lang === 'en';                       // 給 JS 動態字串用
if (L) {
  document.documentElement.lang = 'en';
  document.querySelectorAll('[data-i18n]')
          .forEach(e => e.textContent = EN[e.dataset.i18n]);
}
```

`<title data-i18n="title">` 也走同一條路，不需要特別處理。

**注意 `textContent` 會吃掉子元素。** 根頁 `:109` 是 `<span>原始碼在 <a>GitHub</a></span>`，直接掛在外層 `span` 上會把連結刪掉。要把文字自己包一層：

```html
<span><span data-i18n="source">原始碼在</span> <a class="plain" href="…">GitHub</a></span>
```

英文 "Source on GitHub" 語序相同，文字在連結前，這個包法兩種語言都成立。實作時逐一確認每個 `data-i18n` 的節點只含純文字。

切換 = 寫 localStorage 後 `location.reload()`。不做雙向 DOM 還原：省掉「保存中文原文」與「重新渲染動態清單」兩件事。代價是時鐘動畫重跑一次 —— 這些時鐘的畫面狀態每分鐘本來就會重來，且切語言是一天一次的動作。

JS 裡的動態字串（帶變數，無法掛 `data-i18n`）用 inline 三元，不建第二份字典：

```js
img.alt = L ? `${c.name} screen` : `${c.name}的畫面`;
```

### 字典不抽成共用檔案

每頁內嵌自己的字典。抽成 `/i18n.js` 需要改 8 個 `sw.js` 的 cache 清單，並跨越各 PWA 的 `scope: "./"` 邊界 —— 為了省 7 座共用的 3 個字串不值得。

### localStorage 跨頁共享

8 座時鐘與根頁同 origin，`localStorage` 是 per-origin，一個 key 全站生效。書籤直接進 `/fog/`、或裝成 PWA 從桌面開，都讀得到根頁存下的選擇；沒有存過就走自動判定。

## 檔案分工

### 根 `index.html`
- `:2` `lang="zh-Hant"` → 英文時改 `en`
- `:6` title、`:97` `.sub`、`:101` 載入中、`:109` 原始碼在、`:140` 尚無截圖 → `data-i18n`
- `:155` `alt`、`:167` `ifr.title`、`:192` 計數、`:194` 空清單、`:200` 讀不到清單、`:201` 找不到 clocks.json → inline 三元
- `:7` `meta description` → 中英並排
- 右上角新增語言鈕

### 8 × `clock.json`
新增 `name_en` / `tagline_en` 兩個欄位。`tools/build.py` **不需要改** —— 它整包帶欄位、只剔除 `shot`，新欄位會自動流進 `dist/clocks.json`。根頁渲染時取 `L ? c.name_en : c.name`。

### 8 × 時鐘 `index.html`
每檔共同處理 `:2` `lang`、`:6` `<title>`、`:7` `meta description`（中英並排）、`:11` `apple-mobile-web-app-title`（改英文，與 manifest 一致）。

畫面上的部分：

| 時鐘 | 畫面文字 | 語言鈕 |
|---|---|---|
| flip `:145-147` / fog `:59-61` / receipt `:58-60` / snake `:58-60` / zen `:58-60` | 安裝、防休眠、全螢幕 | 加進既有按鈕列 |
| galaga `:107,111-116,119,470` | 下一波來襲、安裝、攻擊、24/12 小時、音效、防休眠、全螢幕、鍵盤提示 | 加進既有按鈕列 |
| bricks | 畫面已全英文 | 加進既有按鈕列（`:100-105`） |
| life | 畫面已全英文，且無控制列 | **不加** —— 為一顆鈕新開一排 UI 會破壞它「純畫面」的設計 |

### receipt canvas
- `:251` `'台北店   REG #04'` → `'TAIPEI     REG #04'`（等寬列印風，需保持欄位對齊寬度）
- `:123` `const WD = '日一二三四五六'` + `:253` 畫成 `(三)` → 英文時用 `['SUN','MON','TUE','WED','THU','FRI','SAT']`，畫成 `(WED)`

### 8 × `manifest.webmanifest`
`name` / `short_name` / `description` 換英文，`lang: "en"`。`short_name` 用單字（與資料夾名一致，桌面圖示好辨識）。

### `tools/check.py`
新增一條規則：每個 `clock.json` 必須有非空的 `name_en` 與 `tagline_en`。這是本次唯一的自動檢查，用途是防止日後新增時鐘漏翻譯。

## 刻意不做

- **manifest 動態多語**：PWA manifest 規格不支援 i18n，且這是 GitHub Pages 靜態站，沒有 `Accept-Language` 可談；安裝後的名稱也改不了。統一英文。
- **雙向 DOM 還原**：切換走 reload，見上。
- **life 的語言鈕**：畫面零中文，鈕唯一能改的是 tab 標題。
- **`docs/` 與 `README.md` 的翻譯**：那是給開發者看的，不是使用者可見介面。

## 驗收

1. `python tools/check.py` 通過，且對缺 `name_en` 的 `clock.json` 會報錯。
2. `python tools/build.py` 產生的 `dist/clocks.json` 每筆都含 `name_en` / `tagline_en`。
3. 根頁：中文瀏覽器進去是中文，按 `EN` 後全頁英文（含 8 張卡片的名稱與 tagline、計數列），重新整理維持英文。
4. 書籤直接進 `/fog/`（清空 localStorage）：英文瀏覽器得英文按鈕，中文瀏覽器得中文按鈕。
5. 根頁切成 EN 後點進任一時鐘，該頁是英文。
6. receipt 在英文下帳單印 `TAIPEI` 與 `(WED)`，欄位沒有跑掉。
7. 8 座 manifest 的 `name`/`short_name`/`description` 皆英文、`lang: "en"`。
8. life 頁沒有多出控制列。
